# InnoMaker IMX296 Mono

Комплект для подключения монохромной камеры глобального затвора InnoMaker CAM-IMX296Mono-GS к Radxa Dragon Q6A. В комплект входят оверлеи CAM1, CAM2 и CAM3, установщик и скрипт захвата RAW10 с превью.

На **CAM1/J14 через Radxa AC008** получен кадр 1456 × 1088 в формате `Y10P` на Ubuntu 24.04.5 с ядром `7.0.11-7-qcom`. Во время проверки на CAM2 была включена AR0234. Аппаратной проверки IMX296 на CAM2 и CAM3, съёмки при 60 кадрах/с и внешнего триггера пока нет.

## Установка на плате

Скопируйте каталог [target/sbc/radxa_dragon_q6a](target/sbc/radxa_dragon_q6a/) целиком на Q6A. В этом каталоге выполните:

```sh
sudo python3 install.py --port cam1
```

При замене камеры на занятом порту установщик запрашивает подтверждение. Опция `--replace` позволяет подтвердить замену заранее. После применения конфигурации и обычной перезагрузки выполните `python3 capture.py --port cam1`.
